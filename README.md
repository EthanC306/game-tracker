# game-tracker
Game Tracker is a personal project for expanding my skills in a new stack.

#Purpose
Users will be able to add, edit, remove, and track games in a library.
You will be able to track your playtime, progress, ratings and more.

#Philosophy
This particular project will be NO AI , it is meant purely as a learning experiment,
therefore nothing has been generated and the application may not feel as polished as most apps today (yet).

#Stack
Backend: Java + Spring Boot
Frontend: Bootstrap
Database: MySQL, MongoDB
